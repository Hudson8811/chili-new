# Chili Service Black

Локальная версия сайта Chili Service Black.

## Запуск

Откройте `index.html` напрямую в браузере или запустите корень репозитория через
любой локальный веб-сервер.

Основные файлы:

- `index.html` — страница сайта;
- `templates/alevak-3/css/chili-theme.css` — фирменная тема;
- `templates/alevak-3/img/` — логотип и изображения услуг;
- `LOCAL-MIRROR.md` — информация о локальной копии.
